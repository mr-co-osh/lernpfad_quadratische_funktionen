# Lernpfad quadratische Funktionen

Lernseite zur Einheit „Quadratische Funktionen“ (Mathematik 10, E-Kurs, Ziel: ZAP).

**Adresse für die Klasse:** https://mr-co-osh.github.io/lernpfad_quadratische_funktionen/

## Welche Datei enthält was?

| Datei | Inhalt |
|---|---|
| `index.html` | Startseite mit allen Buttons |
| `startklar.html` | Startklar für Funktionen (Eingangscheck mit Lösungen, Blitz-Trainer) |
| `b1.html` … `b8.html` | Baustein 1 bis 8 (Erklärung, Beispiel, Entdecken, Übungen) |
| `ka.html` | Überblick Klassenarbeit mit Lösungen zur Checkliste |
| `fuev.html` | Musterlösungen zu den FÜV |
| `basis.html` | Basis-Blöcke 1–6 mit Lösungen und Schritt-Trainer |
| `trainer.html` | Trainer mit neuen Aufgaben und Gleichungs-Trainer (mit / ohne Schritte) |
| `labor.html`, `ich-kann.html`, `glossar.html`, `links.html` | Werkzeuge |
| `entdecken/b1.html` … `b7.html` | Entdecken-Seiten (Ziel der QR-Codes auf den Aufgabenblättern) |
| `assets/style.css` | Design für alle Seiten (Farben, Schrift, Kästen) |
| `assets/app.js` | Zeichnen, Labor, Trainer, Ich-kann-Liste, Glossar |
| `assets/explorer.js`, `assets/explorer.css` | Entdecken-Werkzeug mit Schlüssel und Vermutung |
| `assets/schritt-trainer.js` | Schritt-Trainer der Basis-Blöcke |
| `assets/fonts/` | Schriften (lokal, es wird nichts von Google geladen) |

## Eine Seite ändern

1. Datei anklicken → Stift-Symbol („Edit this file“).
2. Text ändern → „Commit changes“.
3. Nach etwa einer Minute ist die Änderung online.

Texte stehen direkt im HTML der jeweiligen Seite. Design-Änderungen in `assets/style.css` wirken auf alle Seiten.

## Hinweise

- Alte Links wie `…/#w3` leiten automatisch auf `b3.html` weiter.
- Schlüssel und Lehrer-Code der Entdecken-Seiten stehen nicht im Klartext in den Dateien.
- Offline: den ganzen Ordner herunterladen und `index.html` öffnen.
