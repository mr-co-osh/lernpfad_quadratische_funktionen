Baustein 6

Nullstellen und quadratische Gleichungen

Ich kann quadratische Gleichungen lösen und damit Nullstellen, Stellen mit f(x) = k und Schnittpunkte berechnen.

PflichtNotizblatt + FÜV 6 · Aufgaben 06 bis Typ B · Basis-Block 5

Unsicher?Gleichungs-Trainer · Trainer „Nullstellen mit pq“ · Basis-Block 4

ExtraTyp C · Entdecken-Kasten (unten)

Erklärung

Erst durch a teilen, sodass x² + px + q = 0 entsteht. Dann die pq-Formel:

x₁,₂ = −p2 ± √(p2)² − q
  • Wert unter der Wurzel > 0: 2 Lösungen; = 0: 1 Lösung; < 0: keine Lösung
  • ax² + bx = 0 → ausklammern: x(ax + b) = 0
  • ax² + c = 0 → nach x² umstellen, Wurzel ziehen (±)
  • f(x) = k: k nach links bringen. f(x) = g(x): gleichsetzen, alles auf eine Seite.
  • Scheitelpunkt: Er liegt genau in der Mitte der Nullstellen: xₛ = (x₁ + x₂) : 2.

Beispiel

Nullstellen von f(x) = x² − 2x − 3:

  1. p = −2, q = −3
  2. x = 1 ± √(1 + 3) = 1 ± 2
  3. x₁ = −1, x₂ = 3

(ZAP 2026) Zwei Flugbahnen mit gleichem Start: Gleichsetzen, dann fällt c weg → ausklammern.

Schnittpunkte berechnen in 4 Schritten

Wie in der ZAP 2024 und 2026: Zwei Bälle starten in derselben Höhe. h(x) = −0,4x² + 2x + 1,5 und k(x) = −0,2x² + 1,2x + 1,5. Wo sind beide gleich hoch?

①−0,4x² + 2x + 1,5=−0,2x² + 1,2x + 1,5gleichsetzen②−0,2x² + 0,8x=0alles auf eine Seite – die 1,5 fällt weg③x(−0,2x + 0,8)=0x ausklammernx=0 oder x = 4−0,2x + 0,8 = 0 → x = 4④h(4)=−0,4 · 16 + 2 · 4 + 1,5 = 3,1y-Wert nicht vergessen!

Antwort: Bei x = 0 starten beide. Nach 4 m sind beide wieder gleich hoch, nämlich 3,1 m. Schnittpunkt (4 | 3,1).

Parabel und Gerade: genauso. Nach Schritt ② bleibt oft ein Zahlglied stehen – dann mit der pq-Formel lösen.

Üben Schritt für Schritt: Schnittpunkt zweier Bahnen

Typische Fehler

  • Nicht durch a geteilt, bevor die pq-Formel benutzt wird.
  • Vorzeichen von p und q falsch abgelesen; das ± vergessen.
  • Im Sachkontext die negative Lösung nicht verworfen.

Gleichungen ohne pq-Formel üben: 0 = 2x² − 32 oder 0 = x² − 6x – erst Schritt für Schritt, dann ohne Schritte.
